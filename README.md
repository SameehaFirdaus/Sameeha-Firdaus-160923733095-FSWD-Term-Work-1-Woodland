## 📌 Project Overview

Woodland Sneaker Store is a premium outdoor footwear e-commerce website designed with a cinematic woodland-inspired visual theme.

The website provides a complete shopping experience from browsing products to cart management and checkout.

## ✨ Features

- Cinematic Woodland-inspired homepage
- Responsive navigation
- Product catalogue with 6 sneakers
- Category filtering
- Add to Bag functionality
- Dynamic cart count
- Quantity increase/decrease
- Remove products from cart
- Automatic subtotal and shipping calculation
- Checkout and payment interface
- Card, UPI and Cash on Delivery options
- Form validation
- Order confirmation screen
- Responsive design for desktop, tablet and mobile
- Local product and forest imagery
- Smooth animations and interactive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
